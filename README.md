# Will it actually rain?

A Singapore rain prediction project built around a practical question: **will it rain near this postal code in the next 30 minutes to 2 hours?** The aim is to combine official forecasts, recent rain-gauge observations and the movement of rain on radar into a local, testable prediction.

## Why?

I just don't feel like waking up at 5am to check the rain map (so far the most accurate way of telling if rain is approaching), and cross-analysing that with the rain prediction nowcast.

I should just be able to wake up and automate that whole sequence of checks.

Or even better, a notification that tells me the prediction just when I need it.

## Okay..?

The hypothesis is that we can automate some of the reasoning a person uses when watching radar loops and checking forecasts to beat the existing rain nowcast, and perhaps improve on existing guidance for a specific location.

This is an experiment, largely unproven but just playing around for fun.
